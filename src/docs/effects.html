Effects

Discrete, composable units of game action — the verbs of Card Game Engine.

Overview

Everything that happens in a game is expressed as an IEffect. Draw a card — effect. Deal 3 damage — effect. Create a token — effect. Chain them together — still just effects all the way down.

Effects are:

  • Atomic — each one does exactly one thing.
  • Composable — wrap multiple effects in a SequenceEffect or ConditionalEffect.
  • Testable — pass a GameContext, get back an EffectResult. No MonoBehaviour required.
  • Event-sourced — built-in effects publish events so listeners can react.

IEffect

EffectResult Execute(GameContext context)

The single method all effects must implement. Returns an EffectResult with a Status of:

StatusMeaning
SuccessThe effect resolved normally.
FizzledNo valid target or nothing to act on — silently does nothing.
InvalidA precondition failed (e.g., null argument). Check your setup.

EffectBase

Abstract base class for all custom effects. Inherit from it to get Source and Controller for free:

C# — Custom effect skeleton 
public sealed class HealEffect : EffectBase
{
    private readonly Player _target;
    private readonly int    _amount;

    public HealEffect(EffectSource source, Player controller,
        Player target, int amount) : base(source, controller)
    {
        _target = target;
        _amount = amount;
    }

    public override EffectResult Execute(GameContext ctx)
    {
        if (_target == null || _amount <= 0)
            return EffectResult.Invalid;

        _target.Life += _amount;
        ctx.EventBus.Publish(new LifeGainedEvent(_target, _amount));
        return EffectResult.Success;
    }
}

Built-in Effects

Zone / Card Movement

EffectWhat it does
MoveEffectMoves a single card from its current zone to a destination zone.
DrawEffectMoves the top N cards from a draw zone to a hand zone.
DiscardEffectMoves a card from hand to graveyard.
DestroyEffectMoves a card to the graveyard and fires CardDestroyedEvent.
ExileEffectMoves a card to an exile zone.
ShuffleIntoDeckEffectMoves a card to a deck zone and shuffles it.
ReturnToHandEffectMoves a card from any zone back to its owner's hand.
CreateTokenEffectCreates one or more token cards and places them in a destination zone. See Tokens.

Stats & Damage

EffectWhat it does
DamageEffectDeals N damage to a card or player.
GainLifeEffectAdds N life to a player.
LoseLifeEffectSubtracts N life from a player.
AddCounterEffectAdds N counters of a given type to a card.
RemoveCounterEffectRemoves N counters of a given type from a card.

Continuous & Copy

EffectWhat it does
ApplyContinuousEffectRegisters a modifier (stat buff, copy, etc.) with ContinuousEffectManager.
ScryEffectPeeks the top N cards of a zone and lets the player reorder them. See Scry.

Composite Effects

EffectWhat it does
SequenceEffectExecutes a list of child effects in order. Stops at the first Invalid result.
ConditionalEffectExecutes one of two effects depending on a predicate evaluated at resolution time.
NoOpEffectAlways returns Success without doing anything. Useful as a placeholder branch.

SequenceEffect example

C# — "Lightning Helix" pattern 
// Deal 3 damage to any target AND gain 3 life
var helixEffect = new SequenceEffect(source, controller,
    new DamageEffect(source, controller, target, 3),
    new GainLifeEffect(source, controller, controller, 3)
);

EffectResult result = helixEffect.Execute(context);

ConditionalEffect example

C# 
// "If you control a Dragon, draw 2 cards; otherwise draw 1."
var drawEffect = new ConditionalEffect(source, controller,
    condition:   () => battlefield.Cards.Any(c => c.IsType(dragonType)),
    ifTrue:      new DrawEffect(source, controller, hand, 2),
    ifFalse:     new DrawEffect(source, controller, hand, 1)
);

EffectSource

Every effect carries an EffectSource that describes why the effect is happening — used for event data and future rules checks (e.g., "was this effect caused by a spell?").

C# 
// Simple description source (good for most use cases)
var source = new EffectSource("Lightning Helix");

// Source tied to a specific card (preferred for played spells)
var source = new EffectSource(card);
