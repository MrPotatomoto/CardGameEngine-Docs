Card Rendering

Bind a live CardInstance to a Unity UI prefab with a single call. CardFaceRenderer populates every visual slot — name, type line, rules text, artwork, and stats — and responds to tap/untap state changes automatically.

Overview

The card rendering system consists of two MonoBehaviours:

  • CardFaceRenderer — the primary view component. Extends the abstract CardView base. Assign it to the root of your card prefab and wire all child UI slots in the Inspector.
  • CardStatDisplay — a small component that lives on each stat chip (e.g. Power/Toughness). Knows which StatDefinition it displays and refreshes itself from a CardInstance or CardDefinition.

A prefab builder (Card Game Engine → Create → Card Prefab) scaffolds a complete 315×440 hierarchy with all slots pre-wired so you can start immediately.

CardFaceRenderer

Extends CardView (abstract base already in the engine). Override entry points:

Inspector slotTypePurpose
Card Name TextTMP_TextDisplays CardDefinition.CardName.
Type Line TextTMP_TextBuilt as "Supertype Type — Subtype" using an em dash.
Rules TextTMP_TextDisplays CardFace.RulesText.
Flavor TextTMP_TextDisplays CardFace.FlavorText; hidden when empty.
Artwork ImageImageAssigned the face's Artwork sprite.
Frame ImageImageAssigned the face's FrameArt sprite.
Stat DisplaysCardStatDisplay[]Each display refreshes itself from the live instance.
Tapped IndicatorGameObjectActivated / deactivated on tap state changes.
Target HighlightImageToggled via SetTargetHighlight(bool).
Selection HighlightImageToggled via SetSelectionHighlight(bool).

Binding a card instance

CardFaceRenderer inherits Bind(CardInstance) from CardView, which stores the instance and calls Refresh(). Typically done when the card enters a visible zone:

C#
// Spawn a card view prefab and bind it to a live CardInstance.
var go       = Instantiate(cardPrefab, handContainer);
var renderer = go.GetComponent<CardFaceRenderer>();
renderer.Bind(cardInstance);

Call renderer.Refresh() any time the card's state changes (stat modifications, rule text updates, etc.).

Highlights

C#
// Show a glow when the card becomes a valid target.
renderer.SetTargetHighlight(true);

// Show a border when the player selects the card.
renderer.SetSelectionHighlight(true);
Both highlight images are separate child Image components so you can assign different colours, sprites, and materials per highlight type entirely from the Inspector — no code changes required.

CardStatDisplay

Place one CardStatDisplay per stat chip on your card prefab. Assign the matching StatDefinition asset and the two TMP labels:

Inspector slotDescription
StatThe StatDefinition this chip represents (e.g. your Power asset).
Value TextTMP_Text that shows the numeric value.
Label TextTMP_Text that shows the stat name (optional — can be left null).

The display exposes two refresh paths:

C#
// During gameplay — reads the live modified value from the CardInstance.
statDisplay.Refresh(cardInstance);

// In the deck builder — reads the base value from the CardDefinition.
statDisplay.RefreshFromDefinition(cardDefinition);

Prefab builder

Run Card Game Engine → Create → Card Prefab to generate Assets/CardPrefab.prefab. The builder:

  1. Creates a 315×440 RectTransform hierarchy (Frame, ArtworkArea, Header, TypeLine, TextBox, StatsArea).
  2. Attaches CardFaceRenderer at the root and two CardStatDisplay components in the stats row.
  3. Wires every [SerializeField] via SerializedObject — no manual slot assignment needed.
  4. Selects and pings the new prefab in the Project window.

Duplicate and restyle the prefab for each card type variant (creature, spell, land, etc.) — the prefab builder gives you a working baseline to style from.

Type line format

CardFaceRenderer builds the type line automatically from the CardDefinition. The format is:

Text
Supertype Type — Subtype
// e.g.  Legendary Creature — Dragon Warrior
//       Instant
//       Artifact — Equipment

The em dash and subtype section are omitted when not present. Supertypes and subtypes are space-joined lists from the card definition arrays.
