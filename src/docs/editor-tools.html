Tools

Editor Tools

Custom inspectors, the Card Preview window, and library generators — all the tooling built into the engine for designing cards and configuring systems without leaving the Unity Editor.

Overview

Card Game Engine ships a full suite of editor tooling that activates automatically when you open any engine asset in the Inspector. There is nothing to configure — custom inspectors replace the default Unity view for every engine ScriptableObject the moment the package is imported.

🔍

Custom Inspectors

Every core asset has a custom inspector that shows an at-a-glance summary: artwork, type lines, range bars, colour swatches, flag chips, and validation warnings.

🃏

Card Preview

A floating window that renders a styled card frame — name, art, type line, rules text, keyword pills, stats — for any selected CardTemplate or CardDefinition.

⚡

Library Generators

One-click tools that scan the project and auto-populate KeywordLibrary and GameAssetRegistry assets from all matching assets in the project.

✓

Inline Validation

Every inspector surfaces configuration errors — missing references, impossible bounds, empty names — as HelpBox warnings before you run the game.

Card Preview window

Open via Window → Card Game Engine → Card Preview. The window docks anywhere in the Unity layout and stays open across Play Mode sessions.

Select any CardTemplate or CardDefinition in the Project window — the preview updates automatically. For multi-face templates, use the ◀ / ▶ toolbar buttons to cycle between faces.

Custom inspectors

Every inspector follows the same pattern: a read-only summary panel at the top, inline validation below it, then the standard serialized-field inspector for editing. The summary refreshes automatically as fields change.

AssetInspector highlights
CardTemplate Per-face foldouts with artwork thumbnail, type line, keyword pills, stats, and ability counts. Select button pings the CardDefinition asset. Validation for missing ID, layout, or null faces.
CardDefinition Artwork thumbnail, card name, type line, rarity/set badge, rules text, flavor text, stats + ability count bar.
DeckDefinition Aggregated deck list with copy-count badges (amber at ≥4), total card count footer, inline format validation panel with a DeckFormatDefinition picker and Validate Now button.
GameDefinition Setup checklist with ✓ / ⚠ / ✗ status rows for every required field: turn structure, stack zone, per-player zones, library and hand zones, players, win conditions, SBAs, and opening hand.
ZoneDefinition Ownership badge (PerPlayer / Shared / PerTeam), flag chips (Stack / Active / Ephemeral), property grid for ordering/visibility/entry position, and a capacity row.
StatDefinition Stat name and abbreviation badge. Visual range bar with min/max labels and a white tick mark at the default value. Plain-English clamping summary. Validates inverted min/max and out-of-bounds defaults.
KeywordDefinition Keyword name in large type, optional short-code badge, Evergreen badge, italic reminder text, and a Card display preview showing FormatReminderLine() output.
KeywordLibrary Keyword count badge, evergreen vs set-specific breakdown, scrollable pill grid (green = evergreen, blue = standard), and an embedded Generate Library button.
FaceLayoutType Property grid with ✓ / ✗ indicators for every boolean rule: can cast non-default face, switches during play, retains counters and tapped state on switch.
CounterType Counter name, italic description, and a stat-effect row showing which stat is modified and the per-counter delta with a coloured +/− sign (green positive, red negative).
DeckFormatDefinition Format name, plain-English rules grid (deck size range, copy limit, set legality), and inline set-code pills when set constraints are enabled.
RarityDefinition Rarity name displayed in its own configured colour, hex code label, and a full-width colour swatch bar.
SetDefinition Set name with a set-code badge matching the style used in DeckFormatDefinitionEditor pills, plus release date.

Library generators

Two generator tools scan the project's AssetDatabase and auto-populate catalog assets. Run them after creating or renaming assets of the relevant type.

Keyword Library Generator

Finds every KeywordDefinition in the project, sorts alphabetically by KeywordName, and writes them into a KeywordLibrary asset.

Two ways to run it:

  1. Inspector button (recommended): Select a KeywordLibrary asset → click Generate Library in the custom inspector panel.
  2. Menu bar: Select a KeywordLibrary asset → Card Game Engine → Generate Keyword Library. The menu item is greyed out when no library is selected.

Asset Registry Generator

Finds all registered asset types (CardTemplate, StatDefinition, CounterType, CardStateFlag, ZoneDefinition, ResourceType, ResourceSubtype), sorts each group by its lookup key, and writes them into a GameAssetRegistry asset used by NoCodeBootstrapper and the serialization system.

To run: Select a GameAssetRegistry asset → Card Game Engine → Generate Asset Registry. A summary dialog confirms how many assets of each type were registered.

See Asset Registry for full details on how the registry integrates with the rest of the engine.

Inline validation reference

Every custom inspector surfaces configuration problems as Unity HelpBox messages — no need to run the game to find broken references. Common warnings:

WarningAssetFix
TemplateId / StatName / ZoneName / CounterName is empty Various definitions Assign a unique string ID — asset resolution via GameAssetRegistry uses these as lookup keys.
Face 0 is null CardTemplate Assign a CardDefinition to the first face slot — without it no CardInstance can be created.
No FaceLayoutType assigned CardTemplate Assign a layout asset — face-switching behaviour is undefined without one.
Stack zone missing / no per-player zones GameDefinition Configure the required zones in Per-Player Zones and Shared Zones arrays.
MinValue > MaxValue StatDefinition Invert the bounds — Clamp() will always return MinValue when this is reversed.
Set constraints on with no sets listed DeckFormatDefinition Add at least one SetDefinition to the Allowed Sets array, or disable set constraints.
Stat Effect enabled but no StatDefinition CounterType Assign a StatDefinition to the Stat Effect field, or disable Has Stat Effect.
