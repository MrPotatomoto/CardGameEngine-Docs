Targeting

Declare what can be targeted — the engine filters candidates and validates legality.

Overview

Targeting in Card Game Engine is declarative. Instead of writing filtering logic in each spell, you describe what kind of thing can be targeted with a TargetRequirement, then resolve it against a set of candidates to get a TargetSet.

This keeps your effect code clean, makes targeting rules reusable across many spells, and allows the engine to validate legality before execution.

ITargetable

Any object that can be the target of a spell or ability must implement ITargetable. The engine provides implementations for:

  • CardInstance — individual cards on the battlefield or in other zones
  • Player — a player (for direct damage, life effects, etc.)
  • Zone — some effects target entire zones

TargetRequirement

A TargetRequirement is a predicate + metadata describing the constraints on a valid target. Build one with the fluent builder:

C# — Common requirement patterns 
// "Target creature an opponent controls"
var req = new TargetRequirement()
    .OfType(creatureType)
    .ControlledBy(ControllerFilter.Opponent);

// "Target creature or player"
var req = new TargetRequirement()
    .OfKind(TargetKind.CreatureOrPlayer);

// "Any target" (creature, planeswalker, or player)
var req = TargetRequirement.AnyTarget;

// Custom predicate
var req = new TargetRequirement()
    .WithPredicate(t => t is CardInstance c && c.GetCounters(plusOnePluOneCounterType) > 0);

TargetSet

A TargetSet is the result of resolving a TargetRequirement against a pool of candidates. It holds both the filtered legal candidates and the chosen targets (selected by the player or AI).

C# 
// 1. Build a pool of candidates from the battlefield
var candidates = battlefield.Cards
    .Cast<ITargetable>()
    .Concat(new ITargetable[] { opponentPlayer });

// 2. Resolve the requirement to get legal targets
var targetSet = req.Resolve(candidates, castingPlayer);

// 3. Check legality before presenting to player
if (!targetSet.HasLegalTargets)
{
    // Spell fizzles — no valid targets
    return EffectResult.Fizzled;
}

// 4. Player / AI chooses from legal targets
targetSet.Choose(chosenTarget);

// 5. Validate again at resolution (target may have become illegal)
if (!targetSet.IsStillLegal())
    return EffectResult.Fizzled;

// 6. Use chosen targets
foreach (var t in targetSet.Chosen)
    new DamageEffect(source, controller, t, 3).Execute(context);

Multi-target

For spells that target multiple things (e.g., "destroy up to two target creatures"), set the target count on the requirement:

C# 
// "Destroy up to two target creatures"
var req = new TargetRequirement()
    .OfType(creatureType)
    .WithCount(min: 0, max: 2);
Shroud & Hexproof: Cards with shroud or hexproof can be added to the illegal list of a TargetRequirement through the WithPredicate API or by overriding IsLegalTarget() on the card. The engine will automatically exclude them from targetSet.LegalCandidates.
