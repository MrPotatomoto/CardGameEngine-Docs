Campaign System

Model a full story campaign or challenge ladder as a graph of CampaignNodes. Each node can run a PuzzleDefinition scenario or a free-play match, unlock cards and deck slots on completion, and gate access behind prerequisite nodes — all configured without writing code.

Overview

The campaign system is built from five types:

  • CampaignDefinition — the root asset: campaign name, banner, starting deck, optional format, and the list of nodes.
  • CampaignNode — a [Serializable] class that lives inside a CampaignDefinition. References an optional PuzzleDefinition and CampaignReward, plus a list of prerequisite node IDs.
  • CampaignReward — a ScriptableObject describing what the player earns: card unlocks, extra deck slots, and starting resource bonuses.
  • CampaignSaveData — a [Serializable] class persisted as JSON in Application.persistentDataPath. Tracks completed nodes, claimed rewards, and unlocked card IDs.
  • CampaignManager — a MonoBehaviour that loads/saves data, gates node access, applies rewards, and fires events your UI can react to.

CampaignDefinition

Create via Card Game Engine → Campaign → Campaign Definition.

FieldDescription
Campaign NameDisplay name (also used as the save file identifier).
DescriptionOverview text shown on the campaign-select screen.
Banner ArtSprite shown on the campaign-select screen.
Starting DeckThe deck the player begins the campaign with.
FormatOptional DeckFormatDefinition that restricts deck building during this campaign.
NodesAll CampaignNodes in display order.
C#
// Look up a node by its string ID.
CampaignNode node = campaign.GetNode("boss_1");

CampaignNode

A CampaignNode is a serializable class nested inside CampaignDefinition.Nodes. Each node has:

FieldDescription
Node IdUnique string identifier used in save data and prerequisite lists. Must be unique within the campaign.
Node NameDisplay name shown on the campaign map tile.
DescriptionFlavour text shown when the player selects the node.
Map IconSprite for the map tile.
PuzzleThe PuzzleDefinition to run. Leave null for a free-play opponent match.
RewardThe CampaignReward granted on completion. Leave null for no reward.
Required Node IdsNodeIds that must be completed before this node unlocks. Leave empty to make it available from the start.

CampaignReward

Create via Card Game Engine → Campaign → Campaign Reward.

FieldDescription
DescriptionShort text shown in the reward overlay (e.g. "You earned 2 new cards!").
Unlocked CardsCardTemplate[] added to the player's collection.
Bonus Deck SlotsExtra deck save slots granted. 0 = no change.
Starting Resource BonusesResourceGrantEntry[] applied at the start of each future game session.

CampaignSaveData

Save data is managed automatically by CampaignManager. The save file is stored at:

Text
Application.persistentDataPath / <CampaignName>.campaign.json

You can interact with save data directly if needed:

C#
// Load manually (returns null if no file exists).
var save = CampaignSaveData.Load("My Campaign");

// Check node and prerequisite state.
bool done  = save.IsNodeCompleted("boss_1");
bool ready = save.ArePrerequisitesMet(node.RequiredNodeIds);
bool owned = save.IsCardUnlocked("dragon_001");

// Serialize to JSON string.
string json = save.ToJson();

// Delete a save file.
CampaignSaveData.Delete("My Campaign");

CampaignManager

Attach CampaignManager to a persistent scene object (e.g. your game manager singleton).

Setup

  1. Assign a CampaignDefinition in the Inspector.
  2. Optionally assign a GameAssetRegistry so unlocked card IDs are resolved back to CardTemplate assets after loading.
  3. Call LoadCampaign() on scene start. If no save file exists a fresh one is created automatically.
  4. Wire OnNodeCompleted, OnRewardClaimed, and OnCampaignCompleted to your UI.
C#
void Start()
{
    campaignManager.LoadCampaign();
    RefreshMapUI();
}

void RefreshMapUI()
{
    foreach (var node in campaignManager.Campaign.Nodes)
    {
        bool available = campaignManager.IsNodeAvailable(node);
        bool completed = campaignManager.IsNodeCompleted(node);
        bool locked    = campaignManager.IsNodeLocked(node);
        mapTile.SetState(node, available, completed, locked);
    }
}

Completing a node

Call CompleteNode(node) from your match result handler (e.g. inside PuzzleRunner.OnWin):

C#
// Wire PuzzleRunner.OnWin to this method in the Inspector.
public void OnPuzzleWon(PuzzleCondition condition)
{
    campaignManager.CompleteNode(currentNode);
    // OnNodeCompleted and OnRewardClaimed fire automatically.
    // The save is written to disk immediately.
}

Events

EventPayloadFired when
OnNodeCompletedCampaignNodeA node is marked complete. Use to trigger map animations.
OnRewardClaimedCampaignRewardA reward is applied. Use to show the reward overlay.
OnCampaignCompleted—Every node in the campaign is complete. Use to trigger the end credits.

Additional API

C#
// All CardTemplate assets the player has unlocked so far.
IReadOnlyList<CardTemplate> unlocked = campaignManager.UnlockedCards;

// Save manually (also auto-saves on ApplicationPause and ApplicationQuit).
campaignManager.SaveCampaign();

// Delete all progress and start fresh.
campaignManager.ResetCampaign();

// Check campaign completion without triggering events.
bool finished = campaignManager.IsCampaignComplete();
CampaignManager auto-saves on OnApplicationPause and OnApplicationQuit, so players never lose progress to an unexpected close. For additional safety, call SaveCampaign() after any meaningful state change (e.g. after displaying the reward overlay).
