State-Based Actions

Automatic game rules checked continuously — creatures die from lethal damage, players are eliminated at 0 life, tokens vanish from zones where they shouldn't exist.

Overview

State-based actions (SBAs) are rules the game enforces automatically without any player action. The classic examples: a creature with lethal damage is moved to the graveyard; a player at 0 or fewer life loses the game; a legend rule violation causes one copy to be destroyed.

StateBasedActionManager holds a list of registered IStateBasedAction objects. The game state machine calls CheckAndResolve() before each priority grant. The manager scans all registered actions simultaneously, resolves all violations found in one pass, then repeats until no new violations appear or the safety cap is reached.

Note: SBA effects execute directly — they do not go on the stack. Players cannot respond to them. However, the zone transfers and stat changes they cause fire normal events, so triggered abilities still react normally.

Built-in SBAs

All built-in SBAs are ScriptableObject assets created via Create → Card Game Engine → Rules → ….

LethalDamageSBA

Moves creatures whose toughness stat has dropped to zero or below to a destination zone (typically the graveyard). Configure the stat to watch and the destination zone type in the Inspector.

ZeroToughnessSBA

Similar to LethalDamageSBA but watches for toughness equal to exactly zero, useful for games where toughness and damage are tracked separately (e.g. toughness as base value, damage as a separate stat).

PlayerEliminationSBA

Eliminates a player whose configured PlayerStatDefinition has reached the elimination threshold (typically 0 life or 10 poison counters).

LegendaryRuleSBA

Enforces the legend rule: if a player controls two or more legendary permanents with the same name, they must keep one and send the rest to the graveyard.

TokenCleanupSBA

Removes token cards from zones where tokens cannot legally exist (any zone other than the battlefield, or whichever zone type you configure). Tokens entering non-active zones are simply removed from the game.

AttachmentFallOffSBA

Detaches attachments whose host has left the active zone. See the Attachments page for setup.

Setting up SBAs

C# — Registering SBAs at game start 
// All of these are ScriptableObject assets assigned in the Inspector
var sba = context.StateBasedActionManager;

sba.Register(lethalDamageSBA);       // creatures die at 0 toughness
sba.Register(playerEliminationSBA);  // players die at 0 life
sba.Register(legendaryRuleSBA);      // legend rule
sba.Register(tokenCleanupSBA);       // tokens vanish outside active zones
sba.Register(attachmentFallOffSBA);  // equipment detaches when host leaves

When SBAs run

The game state machine calls CheckAndResolve() automatically before each priority grant. You can also call it manually after any game action that might create a new violation:

C# — Manual check after damage 
// After resolving combat damage, check for dead creatures immediately
int passes = context.StateBasedActionManager.CheckAndResolve();
Debug.Log($"{passes} SBA pass(es) were needed.");

Writing a custom SBA

Implement IStateBasedAction and return an SBAResult when the violation is found, or null when the state is clean.

C# — Custom SBA: discard to hand size 
using UnityEngine;
using CardGameEngine;

[CreateAssetMenu(menuName = "My Game/Hand Size SBA")]
public class HandSizeSBA : ScriptableObject, IStateBasedAction
{
    [SerializeField] private ZoneDefinition _handDef;
    [SerializeField] private ZoneDefinition _graveyardDef;
    [SerializeField] private int _maxHandSize = 7;

    public SBAResult Check(GameContext context)
    {
        foreach (var zone in context.ZoneManager.GetAllZones())
        {
            if (zone.Definition != _handDef) continue;
            if (zone.Count <= _maxHandSize) continue;

            // Player needs to discard — return a violation
            var graveyard = context.ZoneManager.GetZone(_graveyardDef, zone.Owner);
            if (graveyard == null) return null;

            var source = new EffectSource(Guid.NewGuid(), "Hand Size SBA");
            var effect = new MoveCardEffect(source, zone.Owner, graveyard);
            effect.Targets.Add(zone.Top); // discard topmost card

            return new SBAResult(effect,
                $"{zone.Owner.DisplayName} has {zone.Count} cards in hand (max {_maxHandSize}).");
        }
        return null;
    }
}
