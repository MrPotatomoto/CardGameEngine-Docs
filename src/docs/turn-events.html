Turn Events & Bus

Every game event — turn boundaries, phase transitions, step entries, priority grants, zone transfers, and stack operations — now flows through both the ReplacementEffectLayer and the EventBus. Triggered abilities, audio hooks, and UI listeners can subscribe to the full event stream.

Overview

Prior to v6.0, all turn structure and zone events went through ReplacementEffectLayer.Process() only. The EventBus received stack events when abilities were pushed, but turn, phase, step, and priority events were never published to it. This meant triggered abilities could not fire on phase transitions, and audio hooks could not react to turn boundaries.

v6.0 introduces FireEvent<T>() on GameStateMachine — an internal helper that routes every event through the full pipeline:

  1. ReplacementEffectLayer.Process() — replacement effects may transform or suppress the event before anything reacts.
  2. EventBus.Publish() — broadcasts the (possibly modified) event to all subscribers, so triggered abilities queue up and audio hooks fire.
The EventBus walks up the class hierarchy when dispatching, so subscribing to a base type (e.g. GameEvent) receives every event. Subscribe to a specific type (e.g. TurnStartedEvent) for targeted reactions.

Turn structure events

All of these events are now published to the EventBus in addition to being processed by the ReplacementEffectLayer:

Event typeWhen it fires
TurnStartedEventBefore the first phase of each turn.
TurnEndedEventAfter the last phase of each turn.
PhaseEnteredEventWhen a phase begins (after the skip check).
PhaseExitedEventWhen a phase ends.
PhaseSkippedEventWhen a phase is skipped by a replacement or skip rule.
StepEnteredEventWhen a step begins (after the skip check).
StepExitedEventWhen a step ends.
StepSkippedEventWhen a step is skipped.
PriorityGrantedEventEach time a player receives priority in an APNAP round.
PriorityPassedEventEach time a player passes priority.
CardEnteredZoneEventAfter a card arrives in its new zone via ZoneManager.Transfer().
CardLeftZoneEventAfter a card leaves its previous zone via ZoneManager.Transfer().
StackEntryResolvedEventAfter the top stack entry executes successfully.
StackEntryFizzledEventAfter the top stack entry fizzles (targets invalid, or no effect).
StackEntryPushedEventAfter a triggered ability is placed on the stack.

Subscribing to events

Subscribe via EventBus.Subscribe<T>() at any point after the GameContext is created. Always unsubscribe when you no longer need the events:

C#
// Subscribe in session setup:
context.EventBus.Subscribe<TurnStartedEvent>(OnTurnStarted);
context.EventBus.Subscribe<CardEnteredZoneEvent>(OnCardEnteredZone);

// Handlers:
private void OnTurnStarted(TurnStartedEvent e)
{
    Debug.Log($"Turn {e.TurnNumber} — active player: {e.ActivePlayer.Name}");
}

private void OnCardEnteredZone(CardEnteredZoneEvent e)
{
    Debug.Log($"{e.Card} entered {e.Destination.Definition.ZoneName}");
}

// Unsubscribe when the session ends:
context.EventBus.Unsubscribe<TurnStartedEvent>(OnTurnStarted);
context.EventBus.Unsubscribe<CardEnteredZoneEvent>(OnCardEnteredZone);

Triggered abilities on phase transitions

Because turn and phase events now reach the EventBus, you can register triggered abilities with the TriggerRegistry that fire on phase entry or turn start. The trigger fires, queues up in the registry, and RunSBAsAndDrainTriggers() pushes it to the stack (or executes it immediately if BypassesStack = true) in the same window as any other trigger.

Ordering: The ReplacementEffectLayer always runs before the EventBus. A replacement effect can modify or suppress an event before any triggered ability or audio hook sees it. This ordering is intentional and matches Magic: the Gathering's rules architecture.

Session cleanup

Call EventBus.Clear() when tearing down a game session to remove all subscriptions and free all handler references:

C#
// In your session teardown:
context.EventBus.Clear();

Alternatively, individually unsubscribe each handler if you want to reuse the GameContext across multiple games in the same session (e.g. in a best-of-three match).
