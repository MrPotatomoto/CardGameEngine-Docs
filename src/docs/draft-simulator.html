Draft & Booster System

Define booster pack slot rules as ScriptableObjects and simulate sealed-pool events in the Unity Editor. Randomly generated pools can be exported as DeckDefinition assets for immediate use.

Overview

The draft and booster system has two data assets and one editor window:

  • BoosterPackDefinition — defines the slot composition of a single pack. Each slot specifies a pool of eligible CardTemplate assets, a count, an optional rarity filter, and whether duplicates are allowed within that slot.
  • DraftConfig — configures an event: which pack, how many players, packs per player, and sealed vs. draft mode.
  • Draft Simulator window — generates and previews packs or sealed pools entirely in the Editor. Supports fixed-seed generation for repeatable results and exports any pool as a new DeckDefinition.

BoosterPackDefinition

Create via Card Game Engine → Draft → Booster Pack. Add one BoosterSlotRule per rarity band in the Slots array.

Slot rule fields

FieldTypeDescription
LabelstringDisplay name for this slot, e.g. "Commons" or "Rare/Mythic".
PoolCardTemplate[]All cards eligible for this slot. Drag CardTemplate assets here.
CountintHow many cards to draw from this pool per pack.
RarityFilterRarityDefinitionOptional. When set, only cards whose default face has this rarity are eligible.
AllowDuplicatesboolWhen false (default), the same card cannot appear more than once in this slot per pack. When true, sampling is with replacement.
Example — 15-card booster:
Slot 0: Label = "Commons", Count = 10, AllowDuplicates = false
Slot 1: Label = "Uncommons", Count = 3, AllowDuplicates = false
Slot 2: Label = "Rare/Mythic", Count = 1, AllowDuplicates = false
Slot 3: Label = "Basic Land", Count = 1, AllowDuplicates = true

Inspector

The custom inspector shows a header with the pack name and nominal card count, a color-coded slot grid listing each slot's pool size, rarity filter, and count, and any validation warnings (empty pool, pool smaller than count). An Open in Draft Simulator button jumps straight to the window with this pack loaded.

Runtime API

C#
// Generate one pack with a seeded RNG for deterministic results
var rng  = new System.Random(seed: 42);
CardTemplate[] pack = packDef.GeneratePack(rng);

// Generate 6 packs in sequence (for a sealed pool)
CardTemplate[][] sixPacks = packDef.GeneratePacks(6, rng);

// Validate before use
List<string> warnings = packDef.Validate();
foreach (var w in warnings) Debug.LogWarning(w);

DraftConfig

Create via Card Game Engine → Draft → Draft Config. Pair with a BoosterPackDefinition to configure an event.

FieldDefaultDescription
PackDefinition—The booster pack to generate packs from.
PlayerCount8Number of players at the table (1–12).
PacksPerPlayer3Packs each player opens over the event.
SealedFormatfalseWhen true, packs are not passed — each player builds from their own pool only.

Draft Simulator window

Open via Window → Card Game Engine → Draft Simulator.

Pack Preview mode

Assign a BoosterPackDefinition and click New Pack to generate a single randomized pack. The card list shows name, type line, rarity, and set code. Click any card row to ping its asset in the Project window.

Sealed Pool mode

Assign a DraftConfig (or set a pack, player count, and packs per player manually), then click Regenerate All. Each player's pool appears on a separate tab labeled P1, P2, etc. with the total card count.

Fixed seed

Enable the Fixed seed toggle in the toolbar and enter an integer seed. All generation uses a System.Random seeded with that value, producing identical results every time — useful for testing balance, reproducing reported pools, and documenting specific pack distributions.

Exporting a pool

In Sealed Pool mode, click Export Player N Pool as Deck to save the selected player's cards as a DeckDefinition asset. Cards are grouped by template so the entry count reflects how many copies of each card appeared. The asset opens selected in the Inspector.
