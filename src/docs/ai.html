AI Players

Add computer-controlled opponents with AIPlayer and IAIStrategy. Choose from three built-in strategies or plug in your own scoring logic.

Overview

The AI system is built around two concepts:

  • AIPlayer — bridges the GameStateMachine priority callbacks to a strategy. It collects all legal actions (card plays and ability activations) and passes them to the strategy each turn.
  • IAIStrategy — a single-method interface that receives an AIDecisionContext and returns one AIAction to execute, or null to pass priority.

Basic setup

Create an AIPlayer with a Player and a strategy, then assign it to the state machine's priority callback. The example below creates a CPU player using RandomStrategy:

C# — Single AI opponent 
var aiPlayer = new AIPlayer(cpuPlayer, new RandomStrategy());

machine.OnPriorityWindowAsync = (player, tc, gc) =>
    aiPlayer.HandlePriorityAsync(player, tc, gc, destroyCancellationToken);

For a mixed human + AI game, branch on the player in the same delegate:

C# — Human vs AI 
machine.OnPriorityWindowAsync = async (player, tc, gc) =>
{
    if (player == cpuPlayer)
        return await aiPlayer.HandlePriorityAsync(player, tc, gc, ct);

    // Human player — wait for input from your UI layer
    return await humanInput.WaitForDecisionAsync(player, tc, gc, ct);
};
Note: HandlePriorityAsync ignores calls for players that don't match its Player property and returns true (pass) immediately. This means you can safely pass it the full delegate for all players — it only acts when the right player receives priority.

AIDecisionContext

Every call to IAIStrategy.ChooseActionAsync receives an AIDecisionContext with everything the strategy needs:

PropertyDescription
PlayerThe player who is deciding.
TurnContextCurrent phase, step, and allowed action types.
GameContextFull live game state — zones, stats, resource pools, etc.
LegalActionsPre-collected list of every AIAction the player can legally take right now.

LegalActions is built by AIPlayer before invoking the strategy. It iterates every zone for cards the player can cast and calls ActivateAbilitySystem.GetLegalActivations(player). Actions that require targets have CanExecuteWithoutTargets = false — built-in strategies skip these unless a TargetSelector has been assigned.

Built-in strategies

PassAlwaysStrategy

Always returns null — the player passes priority every time without taking any action. Useful as a placeholder, for fully-passive test opponents, or as a fallback in composed strategies.

C# 
var ai = new AIPlayer(cpuPlayer, new PassAlwaysStrategy());

RandomStrategy

Picks a random immediately-executable action from LegalActions. Only actions with CanExecuteWithoutTargets = true are considered (actions that need a target selector are skipped unless one has been set).

The optional PassRate property (0–1) makes the strategy randomly pass even when actions are available — useful for simulating hesitant or unpredictable opponents:

C# — RandomStrategy with 30 % pass rate 
var strategy = new RandomStrategy { PassRate = 0.3f };
var ai = new AIPlayer(cpuPlayer, strategy);

// Use a fixed seed for deterministic replay in tests:
var deterministicAi = new AIPlayer(cpuPlayer, new RandomStrategy(seed: 42));

ScoredStrategy

Scores every candidate action using an IActionScorer and picks the one with the highest score. If the best score is ≤ PassThreshold (default: float.NegativeInfinity), the strategy passes. Set PassThreshold = 0f to pass whenever the best available action is neutral or worse.

C# — Custom scorer 
public class AggressiveScorer : IActionScorer
{
    public float Score(AIAction action, AIDecisionContext ctx)
    {
        // Prefer playing cards; ability activations are secondary.
        if (action.Type == AIActionType.PlayCard)
        {
            var face = action.Card?.CurrentFace;
            if (face == null) return 0f;
            // Higher power = higher score
            return face.GetStat("Power");
        }
        return 0.5f; // flat score for ability activations
    }
}

var ai = new AIPlayer(cpuPlayer,
    new ScoredStrategy(new AggressiveScorer()) { PassThreshold = 0f });

Writing a custom strategy

Implement IAIStrategy — a single async method that receives the decision context and returns an AIAction or null:

C# — Custom strategy skeleton 
public class MyStrategy : IAIStrategy
{
    public Task<AIAction> ChooseActionAsync(
        AIDecisionContext ctx,
        CancellationToken ct = default)
    {
        // Evaluate ctx.LegalActions, read ctx.GameContext, etc.
        // Return an action to take it, or null to pass priority.
        foreach (var action in ctx.LegalActions)
        {
            if (action.CanExecuteWithoutTargets && IsGoodPlay(action, ctx))
                return Task.FromResult(action);
        }
        return Task.FromResult<AIAction>(null);
    }

    private bool IsGoodPlay(AIAction action, AIDecisionContext ctx)
    {
        // your logic here
        return true;
    }
}
Async strategies: You can await in ChooseActionAsync — for example, to call an inference API or run a background Monte-Carlo search. All reads and writes to GameContext must happen on the Unity main thread; marshal back with UnityMainThreadDispatcher or equivalent if you spin off background work.

Target selection for AI

Actions that require targets have CanExecuteWithoutTargets = false. To execute one, assign a TargetSelector delegate that returns the chosen targets:

C# — Assigning targets in a custom strategy 
foreach (var action in ctx.LegalActions)
{
    if (!action.CanExecuteWithoutTargets)
    {
        // Pick the weakest opposing creature as a target.
        var target = FindWeakestOpponentCreature(ctx);
        if (target != null)
        {
            action.TargetSelector = () => new[] { target };
            return Task.FromResult(action);
        }
        continue; // no valid target found — skip this action
    }
}

Sync vs async priority callbacks

AIPlayer provides both an async and a sync wrapper:

  • HandlePriorityAsync(player, tc, gc, ct) — use with machine.OnPriorityWindowAsync. Works with any strategy, including ones that await.
  • HandlePriority(player, tc, gc) — use with machine.OnPriorityWindow. Blocks the calling thread. Only safe with strategies that complete synchronously (PassAlwaysStrategy, RandomStrategy, ScoredStrategy with a sync scorer).
