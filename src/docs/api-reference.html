API Reference

Complete listing of all public types in CardGameEngine v1.

GameContext

The root object for a game session. Pass it to every effect. Does not inherit from MonoBehaviour.

MemberTypeDescription
ZoneManagerZoneManagerRegistry for all zones. Handles zone lookup and card transfers.
EventBusEventBusTyped pub/sub event dispatcher.
ContinuousEffectManagerContinuousEffectManagerManages active continuous effects and computes card states.
ReplacementEffectLayerReplacementEffectLayerIntercept and replace events before resolution.
