Replacement Effects

Intercept events before they resolve — prevent damage, redirect draws, and reroute zone entries — using Inspector-configurable ScriptableObject blueprints.

Overview

The replacement effect system is covered in Events → Replacement Effects. This page documents the three built-in blueprint types that you configure in the Inspector, create runtime instances from, and register with the ReplacementEffectLayer.

Each blueprint follows the same lifecycle:

  1. Create the ScriptableObject asset and configure it.
  2. When the providing card enters play (or at game start for global effects), call CreateReplacementEffect(source, controller) and register the returned object with context.ReplacementEffectLayer.Register(effect).
  3. Store the registered object's ReplacementId (Guid).
  4. When the card leaves play, call context.ReplacementEffectLayer.Unregister(replacementId).

Damage Prevention

Create via: Create → Card Game Engine → Replacement Effects → Damage Prevention.

Intercepts CardDamagedEvent and/or PlayerDamagedEvent and reduces the damage amount. If the remaining amount reaches zero, the event is fully suppressed.

Inspector fields

FieldDescription
Card FilterOptional — only prevent damage to cards matching this filter. Leave empty to prevent damage to any card.
Player TargetNone / ActivePlayer / PriorityPlayer — extend prevention to a player role as well.
Damage TypeOptional — only prevent damage of this type. Leave empty for any type.
Prevent AmountHow much to reduce per event. -1 = prevent all damage.
Is MandatoryIf false, the controller is asked whether to apply it.
C# — "Prevent all damage to target creature this turn" 
var protection = damagePrevDef.CreateReplacementEffect(source, controller);
context.ReplacementEffectLayer.Register(protection);
Guid savedId = protection.ReplacementId;

// When the turn ends or the card leaves:
context.ReplacementEffectLayer.Unregister(savedId);

Draw Replacement

Create via: Create → Card Game Engine → Replacement Effects → Draw Replacement.

Intercepts CardEnteredZoneEvent for draws (identified by a TransferTag) and redirects the card to an alternate zone instead of the hand. The original hand-entry event is suppressed.

Common uses: "exile cards you would draw instead"; "drawn cards are placed on the bottom of your library."

Inspector fields

FieldDescription
Draw TagThe TransferTag your DrawCardEffect uses. Only transfers with this tag are treated as draws.
Hand Zone TypeThe ZoneType of the player's hand.
Card FilterOptional — only replace draws of cards matching this filter.
Redirect Zone TypeWhere to send the drawn card instead of the hand.
Is MandatoryIf false, the controller chooses whether to apply it.

Zone-Change Replacement

Create via: Create → Card Game Engine → Replacement Effects → Zone Change Replacement.

Intercepts CardEnteredZoneEvent for a specific zone type (and optionally a specific transfer tag or card filter) and immediately redirects the card to a different zone. The original entry is suppressed.

Common uses: "if a creature would die, exile it instead"; "if a card would be put into your graveyard from anywhere, exile it instead."

Inspector fields

FieldDescription
Intercept Zone TypeThe zone type to watch — e.g. "Graveyard".
Card FilterOptional — only intercept cards matching this filter.
Transfer TagOptional — only intercept transfers with this tag.
Redirect Zone TypeWhere to send the card instead — e.g. "Exile".
Is MandatoryIf false, the controller chooses whether to apply it.
Tip: Chain multiple zone-change replacements carefully. Each one applies at most once per event. If the redirect zone type matches the intercept zone type, the effect skips itself to avoid re-triggering.
