Multiplayer & Netcode

Send player decisions over any network backend using a transport-agnostic abstraction. Implement IGameTransport once for your chosen backend (Unity Netcode, Mirror, Photon, raw TCP…) and the rest of the engine never changes.

Overview

The multiplayer system is built around three ideas:

  • Host/client model. One machine runs the authoritative GameContext (the host). Other players are clients that send GameNetworkAction messages describing their decisions; the host applies them and broadcasts state snapshots.
  • Transport abstraction. IGameTransport is a small interface — Connect, Disconnect, Send, and four events. Swap backends by swapping the implementation; session logic never changes.
  • Serialized decisions. GameNetworkAction is a plain [Serializable] class transmitted as JSON. It captures enough information (card GUIDs, ability names, target lists) to replay any legal game action on the host.

IGameTransport

Implement this interface to connect the engine to your chosen backend.

MemberDescription
bool IsConnectedTrue while an active connection exists.
string LocalPlayerIdStable ID for the local endpoint. Set as SenderId on all outgoing messages.
void Connect()Initiates the connection asynchronously. Raises OnConnected on success.
void Disconnect()Closes the connection. Raises OnDisconnected.
void Send(NetworkMessage)Sends a message to all connected peers.
event OnConnectedRaised when the connection is established.
event OnDisconnectedRaised when the connection closes.
event OnMessageReceivedRaised for each incoming NetworkMessage. Must be raised on the Unity main thread.
event OnErrorRaised on transport-level errors.
If your backend delivers bytes on a background thread, marshal them to the main thread (e.g. via a ConcurrentQueue drained in Update()) before raising OnMessageReceived. The engine assumes all events arrive on the main thread.

LocalGameTransport (testing & hot-seat)

An in-process loopback transport included out of the box. Messages sent on one instance are immediately received by its paired peer — no sockets, no server required.

C#
// Create one transport per player.
var hostTransport   = new LocalGameTransport("host-player");
var clientTransport = new LocalGameTransport("client-player");

// Pair them — both transports raise OnConnected immediately.
hostTransport.ConnectTo(clientTransport);

// Simulate network latency during development.
hostTransport.SimulatedLatencyMs   = 80;
clientTransport.SimulatedLatencyMs = 80;

NetworkGameSession

Attach to your game-session root alongside GameBootstrapper.

Setup

C#
// After GameBootstrapper constructs the GameContext:
networkSession.Initialise(transport, gameContext);

// On the host — assign the remote-player priority handler for each remote seat.
// (Local and AI players keep their existing handlers.)
stateMachine.OnPriorityWindowAsync = async (player, tc, gc) =>
{
    if (player == remotePlayer)
        return await networkSession.HandleRemotePriorityAsync(player, tc, gc);
    return await localAwaiter.HandlePriorityAsync(player, tc, gc);
};

Inspector slots

SlotDescription
Is HostTrue on the authoritative machine; false on clients.
Snapshot IntervalSeconds between full state-snapshot broadcasts from host to clients. Lower = less drift, more bandwidth.
OnSessionConnectedFired when the transport connects.
OnSessionDisconnectedFired when the connection is lost.
OnChatReceivedFired with "PlayerName: text" when a chat message arrives.
OnSessionErrorFired on transport errors.

Sending actions from a client

C#
// Pass priority.
networkSession.SendAction(new GameNetworkAction
{
    ActionType = NetworkActionType.PassPriority,
});

// Cast a card.
networkSession.SendAction(new GameNetworkAction
{
    ActionType    = NetworkActionType.PlayCard,
    CardInstanceId = cardInstance.ObjectId.ToString(),
    TargetIds     = new[] { targetCard.ObjectId.ToString() },
});

// Declare attackers.
networkSession.SendAction(new GameNetworkAction
{
    ActionType  = NetworkActionType.DeclareAttackers,
    AttackerIds = attackers.Select(c => c.ObjectId.ToString()).ToArray(),
});

// Send a chat message.
networkSession.SendChat("Good game!");

NetworkMessage & GameNetworkAction

NetworkMessage is the outer envelope; GameNetworkAction is its payload for NetworkMessageType.Action messages. Both are plain [Serializable] classes JSON-encoded via JsonUtility.

PassPrioritynone
