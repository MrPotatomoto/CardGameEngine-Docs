Tokens

Create, track, and clean up token cards — from Soldier tokens to complex creature tokens.

Overview

Tokens are cards that are created during gameplay rather than drawn from a deck. They are backed by a TokenDefinition (a subclass of CardTemplate) and are indistinguishable from regular cards at the CardInstance level — except that card.IsToken returns true.

TokenDefinition

Create via Right-click → Create → Card Game Engine → Token Definition. A TokenDefinition is a CardTemplate subclass — it carries the same face data (name, types, stats), but is tagged so the engine knows it's a token.

No deck needed: Tokens are not part of any player's deck. TokenDefinition assets live in your project as normal ScriptableObjects — reference them in Inspector fields on cards or abilities that create them.

CreateTokenEffect

The built-in effect for creating tokens. It handles all the bookkeeping: instantiating CardInstance objects, setting owner/controller, placing them in the destination zone, and firing the appropriate events.

C# — Create three Soldier tokens 
var effect = new CreateTokenEffect(
    source:      effectSource,
    controller:  castingPlayer,   // becomes owner AND controller of the tokens
    tokenDef:    soldierTokenDef,
    destination: battlefield,
    count:       3
);

EffectResult result = effect.Execute(context);
// result.Status == EffectStatus.Success
// battlefield.Count == 3
// Each token: IsToken = true, Owner = castingPlayer, Controller = castingPlayer

Events Fired

For each token created, CreateTokenEffect fires:

  1. TokenCreatedEvent — carries the newly created token instance.
  2. CardEnteredZoneEvent — fired by ZoneManager.Transfer() as the token enters the destination zone.
C# — Listening to token creation 
context.EventBus.Subscribe<TokenCreatedEvent>(e =>
{
    Debug.Log($"Token created: {e.Token.Face.CardName} controlled by {e.Token.Controller.DisplayName}");
    // Spawn a visual GameObject for the token here
});

Identifying Tokens

Use card.IsToken at any time to check whether a CardInstance is a token. This returns true if and only if the card's template is a TokenDefinition.

C# 
// Count non-token creatures on the battlefield
int realCreatures = battlefield.Cards
    .Count(c => c.IsType(creatureType) && !c.IsToken);

Token Cleanup

Tokens that leave the battlefield are automatically removed — they cease to exist in any zone. This is handled by subscribing to CardLeftZoneEvent and removing the token from its destination zone if the destination is not the battlefield.

Tokens in graveyard: By default, when a token would go to a zone that isn't the battlefield (e.g., a graveyard or exile), it blinks out of existence instead. Implement this as a replacement effect or as a CardLeftZoneEvent handler — the engine does not enforce this rule automatically, giving you control over your game's specific token rules.
C# — Auto-remove tokens on death 
context.EventBus.Subscribe<CardEnteredZoneEvent>(e =>
{
    // If a token just entered any zone other than battlefield, remove it
    if (e.Card.IsToken && e.Zone != battlefield)
    {
        e.Zone.TryRemove(e.Card);
        Debug.Log($"Token {e.Card.Face.CardName} ceased to exist.");
    }
});
