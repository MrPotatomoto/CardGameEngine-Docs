Card Conditions

Three new members on CardInstance — DamageMarked, TurnEnteredZone, and HasSummoningSickness() — give your SBAs and combat system what they need to enforce lethal-damage destruction and summoning-sickness restrictions.

Overview

Previously, tracking per-turn combat damage or whether a card could attack required custom game-specific fields. These three additions bake the most common conditions directly into CardInstance so they are available to every system without duplicating logic.

MemberTypeDescription
DamageMarkedint (read-only)Marked combat damage accumulated this turn. Reset by ClearDamage().
MarkDamage(int)methodAdds marked damage. Negative amounts are ignored.
ClearDamage()methodResets DamageMarked to zero. Call during end-of-turn cleanup.
TurnEnteredZoneintThe turn number when this card most recently entered a zone. Set automatically by ZoneManager.Transfer().
HasSummoningSickness(int, KeywordDefinition?)boolReturns true when the card entered a zone this turn and lacks Haste.

Marked damage

Marked damage is tracked separately from permanent stat values because it:

  • Resets each turn (at end-of-turn cleanup, not end-of-phase).
  • Needs to be queried efficiently by SBAs on every card in play.
  • Is conceptually distinct from a card's toughness stat — it is not a modifier applied to a stat; it is an accumulator that is compared against a stat.

Applying damage

C#
// In a combat damage step:
blocker.MarkDamage(attacker.GetStat(_powerStat));
attacker.MarkDamage(blocker.GetStat(_powerStat));

// Check against toughness in an SBA:
int toughness = card.GetStat(_toughnessStat);
if (card.DamageMarked >= toughness)
    DestroyCard(card);

Clearing damage

Call ClearDamage() on every permanent during the end-of-turn cleanup step, or whenever your rules remove damage from cards:

C#
// In your end-of-turn cleanup auto-action or effect:
foreach (var card in battlefieldZone.Cards)
    card.ClearDamage();
Trample and deathtouch: If your game rules assign damage in excess of toughness (trample) or treat any damage as lethal (deathtouch), implement those rules in your combat system before calling MarkDamage — the engine accumulates whatever value you pass in.

TurnEnteredZone

TurnEnteredZone is set automatically by ZoneManager.Transfer() each time a card moves to a new zone. It holds the value of GameContext.TurnNumber at the moment of entry.

C#
// After a Transfer(), TurnEnteredZone is set:
zoneManager.Transfer(card, battlefield, source);
// card.TurnEnteredZone == context.TurnNumber

Because zone transfers during setup (e.g. DeckDefinition.Populate()) happen before TurnNumber is incremented from 0, cards that enter the game during setup will have TurnEnteredZone = 0 — which means HasSummoningSickness will return false from turn 1 onward unless the card re-enters a zone mid-game. Adjust your combat system if this is not the behaviour you want.

HasSummoningSickness

A card has summoning sickness when it entered a zone on the current turn and does not have Haste:

C#
// Declare a reference to your Haste keyword asset:
[SerializeField] private KeywordDefinition _hasteKeyword;

// In your combat system — filter attackers:
var validAttackers = battlefieldZone.Cards
    .Where(c => c.Controller == activePlayer
             && !c.HasSummoningSickness(context.TurnNumber, _hasteKeyword));

// In a game with no Haste equivalent:
bool sick = card.HasSummoningSickness(context.TurnNumber, hasteKeyword: null);
ParameterDescription
currentTurnPass GameContext.TurnNumber. The method compares this to TurnEnteredZone.
hasteKeywordThe KeywordDefinition asset that grants immunity to summoning sickness. Pass null if your game has no such keyword — sickness will always apply to newly entered cards.
