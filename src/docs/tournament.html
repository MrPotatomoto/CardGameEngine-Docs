Tournament Brackets

Generate pairings, record results, and track standings for Single Elimination or Swiss tournaments — all in a serializable bracket you can save and restore at any point.

Overview

The tournament system has three layers:

  • TournamentDefinition — a ScriptableObject describing the rules: bracket type, max participants, round count, and format.
  • TournamentBracket — the live bracket: participant records, all matches across all rounds, current round index. Serializes to JSON for save/restore.
  • TournamentManager — a MonoBehaviour that creates brackets, generates pairings, records results, and fires events.

TournamentDefinition

Create via Card Game Engine → Tournament → Tournament Definition.

FieldDescription
Tournament NameDisplay name (e.g. "Weekly Showdown").
Bracket TypeSingle Elimination — one loss and you're out. Swiss — everyone plays every round; best record wins.
Max ParticipantsHard cap on registrations. Single Elimination brackets round down to the nearest power of two to fill a clean bracket.
RoundsFor Swiss: number of rounds to play. For Single Elimination: ignored — rounds are derived from bracket size.
FormatOptional DeckFormatDefinition applied to all matches.

TournamentManager

Attach to a persistent scene object and assign a TournamentDefinition in the Inspector.

Creating a tournament

C#
// Pass a list of player display names to generate the bracket and first-round pairings.
tournamentManager.CreateTournament(new[] {
    "Alice", "Bob", "Carol", "Dave",
    "Eve", "Frank", "Grace", "Hank",
});

// OnRoundStarted fires immediately with the first round's matches.

Recording results

C#
// After a match concludes, report the result by match ID.
tournamentManager.ReportResult(match.MatchId, MatchResult.ParticipantAWon);

// OnMatchCompleted fires.
// When all matches in the round are complete, the manager automatically
// advances to the next round (OnRoundStarted fires) or ends the tournament
// (OnTournamentEnded fires).

Events

EventPayloadFired when
OnRoundStartedTournamentBracketA new round's pairings have been generated. Use to refresh bracket UI.
OnMatchCompletedTournamentMatchA result is recorded for a specific match.
OnTournamentEndedTournamentBracketAll rounds are complete. Read GetStandings() for the final ranking.

TournamentBracket

The bracket holds the full live state and exposes several query helpers:

C#
var bracket = tournamentManager.Bracket;

// All participants sorted by match points (wins × 3 + draws × 1).
List<TournamentParticipant> standings = bracket.GetStandings();

// Matches in the current round.
List<TournamentMatch> current = bracket.GetCurrentRoundMatches();

// All matches for one participant.
List<TournamentMatch> history = bracket.GetMatchesFor(participantId);

// Is the current round complete?
bool done = bracket.IsCurrentRoundComplete();

// Save and restore.
string json = bracket.ToJson();
TournamentBracket restored = TournamentBracket.FromJson(json);

Pairing algorithms

TypeAlgorithm
Single EliminationParticipants sorted by seed, then paired 1 vs. last, 2 vs. second-last, etc. Players eliminated after one loss. Byes awarded to odd participants.
SwissParticipants sorted by match points descending. Nearest-record pairing, avoiding rematches where possible. Odd participant receives a bye (counts as a win).

MatchResult values

ValueEffect on records
ParticipantAWonA: +1 win, B: +1 loss
ParticipantBWonA: +1 loss, B: +1 win
DrawBoth: +1 draw (1 match point each)
ByeA: +1 win (auto-generated for odd participant counts)
