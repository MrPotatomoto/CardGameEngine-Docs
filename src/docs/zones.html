Zones

Ordered card collections — deck, hand, graveyard, battlefield, and beyond.

Overview

A Zone is an ordered list of CardInstance objects. Every card in play belongs to exactly one zone at any moment. Zones are defined by ScriptableObject assets (ZoneDefinition) and instantiated at runtime.

The ZoneManager is the authoritative registry for all zones in a game. Moving a card between zones always goes through ZoneManager.Transfer(), which updates both zones and fires the appropriate events.

ZoneDefinition

Create via Right-click → Create → Card Game Engine → Zone Definition. Configure in the Inspector.

FieldTypeDescription
ZoneNamestringDisplay name ("Deck", "Hand", "Battlefield", etc.).
DefaultInsertPositionZoneInsertPositionTop or Bottom — where TryAdd inserts by default.
IsOrderedboolIf false, the zone is treated as unordered (e.g. battlefield).
MaxCapacityint0 = unlimited. Set a positive value to cap zone size (e.g. hand limit).

Zone

Zone is a runtime plain C# class. Instantiate it with a ZoneDefinition and an optional owner player:

C# 
// Shared zone (battlefield) — no owner
var battlefield = new Zone(battlefieldDef, owner: null);

// Player-owned zone
var deck = new Zone(deckDef, owner: player1);

// With a seeded RNG (useful for deterministic tests / replays)
var deck = new Zone(deckDef, owner: player1, rng: new System.Random(42));

Methods

MethodReturnsDescription
TryAdd(card)boolAdds the card at the default insert position. Returns false if the zone is full or card is already present.
TryRemove(card)boolRemoves the card. Returns false if not found.
Contains(card)boolChecks membership without modifying the zone.
PeekTop(n)List<CardInstance>Returns the top n cards (clamped to zone size) without removing them.
Reorder(newOrder)voidReorders the zone to match newOrder. Cards missing from the list are appended at the end.
Shuffle()voidFisher-Yates shuffle using the zone's System.Random instance.

PeekTop & Shuffle examples

C# 
// Peek top 3 cards of the deck (non-destructive)
List<CardInstance> top3 = deck.PeekTop(3);

// Shuffle the deck
deck.Shuffle();

// Reorder after a Scry decision
deck.Reorder(new List<CardInstance> { c2, c1, c3 });

ZoneManager

All zones must be registered with ZoneManager before gameplay begins. The manager tracks zone ownership, handles card transfers, and fires zone events.

C# 
// Register zones once during game setup
context.ZoneManager.Register(deck);
context.ZoneManager.Register(hand);
context.ZoneManager.Register(battlefield);
context.ZoneManager.Register(graveyard);

// Transfer a card from hand to battlefield
// Fires CardLeftZoneEvent (hand) and CardEnteredZoneEvent (battlefield)
context.ZoneManager.Transfer(card, fromZone: hand, toZone: battlefield);

// Look up a zone by its definition asset
Zone found = context.ZoneManager.GetZone(battlefieldDef, owner: null);
Always use Transfer, never TryAdd/TryRemove directly when moving cards between zones during gameplay. Direct manipulation bypasses event firing and can leave card.CurrentZone out of sync.

Zone Events

EventFired when…
CardEnteredZoneEventA card is added to a zone via ZoneManager.Transfer().
CardLeftZoneEventA card is removed from a zone via ZoneManager.Transfer().
C# 
context.EventBus.Subscribe<CardEnteredZoneEvent>(e =>
{
    Debug.Log($"{e.Card.Face.CardName} entered {e.Zone.Definition.ZoneName}");
});
