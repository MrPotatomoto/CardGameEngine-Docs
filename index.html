Define your game logic in pure C#

No visual scripting, no magic strings. Card Game Engine is code-first — every mechanic is a plain C# class you can unit-test, version-control, and reason about.

  • ScriptableObject data — configure in the Inspector, code the rules
  • Full NUnit test suite included — verify your mechanics in Edit Mode
  • Zero singletons — pass GameContext explicitly, test in isolation

C# — Custom Effect 
// A custom effect: drain life from target → gain that much life
public sealed class DrainEffect : EffectBase
{
    private readonly ITargetable _target;
    private readonly int _amount;

    public DrainEffect(EffectSource source,
        Player controller,
        ITargetable target,
        int amount) : base(source, controller)
    {
        _target  = target;
        _amount  = amount;
    }

    public override EffectResult Execute(GameContext ctx)
    {
        var inner = new SequenceEffect(Source, Controller,
            new DamageEffect(Source, Controller, _target, _amount),
            new GainLifeEffect(Source, Controller, Controller, _amount)
        );
        return inner.Execute(ctx);
    }
}
