Continuous Effects

Layer-based stat modifiers and copy effects — computed fresh every time you ask.

Overview

A continuous effect is an ongoing modification to a card's characteristics that persists until an expiry condition is met. Rather than mutating stats directly, the engine computes a card's current state on demand by applying all active modifiers in layer order.

This design means you never have stale stat values — and removing a continuous effect automatically un-does its contribution without requiring explicit rollback code.

Layer System

Modifiers are applied in a defined order (the layer system) to ensure predictable interactions. The layers, in application order:

LayerNameWhat happens
0CopyCard becomes a copy of another card — all characteristics replaced.
1ControlController is changed.
2TypeChangingType line is modified.
3ColorChangingColor is modified.
4AbilityAddingAbilities granted or removed.
5PowerToughnessSetPower/toughness set to a fixed value.
6PowerToughnessModifyPower/toughness adjusted by ±N.
7CounterStatsStat bonuses from counters (e.g. +1/+1 counters).

ContinuousEffectManager

The manager lives on GameContext. Register continuous effects at any time; the engine applies them on the next ComputeState() call.

C# 
// Register a +2/+2 buff for one turn
var modifier   = new StatModifier(card, powerDef, +2);
var continuous = new ContinuousEffect(
    modifier:        modifier,
    source:          effectSource,
    controller:      controller,
    expiryCondition: ExpiryReason.EndOfTurn
);
context.ContinuousEffectManager.Register(continuous);

// Read the current state of the card (base + all modifiers)
var state = context.ContinuousEffectManager.ComputeState(card);
int power = state.GetStat(powerDef);

// Expire all effects marked EndOfTurn
context.ContinuousEffectManager.ExpireEffects(ExpiryReason.EndOfTurn);

// Manually remove a specific effect
context.ContinuousEffectManager.Remove(continuous);

Built-in Modifiers

StatModifier

Adds a flat bonus to a single stat. Applied at layer 6 (PowerToughnessModify) by default.

C# 
// All creatures get +1/+1 (pump spell pattern)
foreach (var c in battlefield.Cards.Where(c => c.IsType(creatureType)))
{
    var mod = new StatModifier(c, powerDef,     +1);
    var mod2= new StatModifier(c, toughnessDef, +1);
    context.ContinuousEffectManager.Register(new ContinuousEffect(mod,  source, ctrl, ExpiryReason.EndOfTurn));
    context.ContinuousEffectManager.Register(new ContinuousEffect(mod2, source, ctrl, ExpiryReason.EndOfTurn));
}

CounterStatModifier (internal)

CounterStatModifier is automatically applied by ComputeState() for any CounterType with Has Stat Effect enabled. You do not construct it directly — configure the CounterType asset in the Inspector instead.

For example, a "+1/+1 counter" type with Value Per Counter set to 1 for both Power and Toughness will cause each counter to contribute +1/+1 in the Counter Stats layer.

BecomesCopyModifier

Applied at layer 0 (Copy). Replaces the target card's type line and stats with those of a source card. The copy is "shallow" — abilities and further modifiers from the source are not inherited by default.

C# — "Clone" card pattern 
// cloneCard enters as a copy of targetCreature
var modifier   = new BecomesCopyModifier(cloneCard, sourceCard: targetCreature);
var continuous = new ContinuousEffect(
    modifier:        modifier,
    source:          effectSource,
    controller:      controller,
    expiryCondition: ExpiryReason.Manual   // persists until removed
);
context.ContinuousEffectManager.Register(continuous);

// Compute state — cloneCard now looks like targetCreature
var state = context.ContinuousEffectManager.ComputeState(cloneCard);
// state.GetStat(powerDef) returns targetCreature's power

ExpiryReason

Controls when an effect is automatically removed. You call ExpireEffects(reason) at the appropriate game phase.

ValueMeaning
ManualNever auto-expires; call Remove() explicitly.
EndOfTurnRemoved when you call ExpireEffects(EndOfTurn).
EndOfCombatRemoved when you call ExpireEffects(EndOfCombat).
UntilLeavesPlayRemoved when the source card's CardLeftZoneEvent fires.
