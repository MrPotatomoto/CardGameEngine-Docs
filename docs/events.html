Events

Typed pub/sub messaging — react to anything that happens in the game.

EventBus

The EventBus is the central communication backbone. It lives on GameContext and lets any part of your game publish events that any other part can react to — without direct coupling between systems.

C# — Subscribe & Publish 
// Subscribe — receive a typed event
context.EventBus.Subscribe<CardEnteredZoneEvent>(e =>
{
    Debug.Log($"{e.Card.Face.CardName} entered {e.Zone.Definition.ZoneName}");
});

// Publish — fire an event to all subscribers
context.EventBus.Publish(new CardEnteredZoneEvent(card, zone));

Unsubscribing

Store the returned subscription handle and dispose it when you're done — e.g., when a card leaves the battlefield:

C# 
IDisposable sub = context.EventBus.Subscribe<TurnStartedEvent>(OnTurnStart);

// Later — clean up
sub.Dispose();

Replacement Effects

A replacement effect intercepts an event before it resolves and substitutes different behavior. Classic use cases: "If a creature would die, exile it instead." or "If you would draw while your library is empty, you lose the game instead."

C# — Indestructible replacement 
context.ReplacementEffectLayer.Register<CardDestroyedEvent>(e =>
{
    // If the target has Indestructible, cancel the destroy
    if (e.Card.HasAbility(indestructibleAbility))
        return ReplacementResult.Cancel;

    return ReplacementResult.Allow;
});
