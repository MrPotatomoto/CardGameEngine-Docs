Serialization

Save and restore complete game state with GameSerializer and GameSnapshot. Record a log of every game event for replay with ReplayLogger.

Overview

Card Game Engine includes two complementary persistence tools:

  • GameSerializer — captures a complete point-in-time snapshot of zone contents, card state, player stats, resources, and turn metadata. Can be round-tripped to/from JSON. Used for save games, server sync, and the undo/checkpoint system.
  • ReplayLogger — records every event published through the ReplacementEffectLayer as an ordered log. Use it to reconstruct what happened during a game for review, analytics, or bug reports.

GameSnapshot

A GameSnapshot is a plain serializable C# object. It contains:

  • Metadata — capture timestamp, turn number, active player index, priority player index.
  • Player names — ordered list used for validation during restore.
  • Zone snapshots — one per registered zone; each contains the ordered list of CardInstanceSnapshot records (template ID, stats, counters, tapped state, face index, active flags).
  • Stack entries — informational only; live effects cannot be reconstructed generically.
  • Resource pools — all player resource pool amounts.
Note: Stack entries are captured for debugging and replay logs, but are not restored. Take snapshots between priority windows (when the stack is empty) for fully restorable saves.

Capturing a snapshot

C# — Saving game state 
var snapshot = GameSerializer.Capture(context, players);
string json    = GameSerializer.ToJson(snapshot);

// Write to disk, send to server, etc.
File.WriteAllText("save.json", json);

Restoring from a snapshot

Restoring requires an IGameAssetResolver — an interface you implement that maps the string IDs in the snapshot back to your game's ScriptableObject assets. Typical implementation: look up assets by name in a pre-built dictionary.

C# — Loading game state 
string json     = File.ReadAllText("save.json");
var snapshot = GameSerializer.FromJson(json);

// resolver maps string IDs back to SO assets
IGameAssetResolver resolver = new MyAssetResolver();

GameSerializer.Restore(snapshot, context, players, resolver);
// Zones are cleared and repopulated; turn/priority state is restored.

Implementing IGameAssetResolver

C# — Minimal resolver 
public class MyAssetResolver : IGameAssetResolver
{
    private readonly Dictionary<string, CardTemplate>     _templates;
    private readonly Dictionary<string, StatDefinition>    _stats;
    private readonly Dictionary<string, CounterType>       _counters;
    // ... other lookups

    public CardTemplate  ResolveTemplate(string id)     => _templates.GetValueOrDefault(id);
    public StatDefinition ResolveStat(string name)      => _stats.GetValueOrDefault(name);
    public CounterType   ResolveCounterType(string name) => _counters.GetValueOrDefault(name);
    // ... implement ResolveStat, ResolveFlag, ResolveZone, etc.
}

ReplayLogger

ReplayLogger subscribes to the ReplacementEffectLayer and records every event that passes through it as a timestamped log entry in a GameReplayLog. The log can be serialized to JSON alongside the initial snapshot to produce a complete replay file.

C# — Recording a game 
// Start logging at game begin
var logger = new ReplayLogger(context);
logger.StartRecording();

// ... game plays out ...

// At game end, capture the log
logger.StopRecording();
var log  = logger.GetLog();
string json = GameSerializer.ToJson(log);
File.WriteAllText("replay.json", json);
