Cards

The three-layer model: static data, templates, and live instances.

Overview

Card Game Engine separates card data from card instances using three types:

  • CardDefinition — the logical face of a card (name, type line, stats, abilities). Pure data, never mutated.
  • CardTemplate — a ScriptableObject that holds one or more CardDefinition faces (for double-faced cards). This is the asset you create in the Project window.
  • CardInstance — a runtime object representing one physical copy of a card. Tracks owner, controller, current zone, counters, and applied effects.

CardDefinition

CardDefinition is a ScriptableObject that stores the immutable characteristics of one card face.

PropertyTypeDescription
CardNamestringDisplay name of the card.
TypesCardType[]Primary types (Creature, Instant, Sorcery, etc.).
SubtypesCardSubtype[]Subtypes (Warrior, Dragon, Equipment, etc.).
SupertypesCardSupertype[]Supertypes (Legendary, Basic, Snow, etc.).
StatsStatEntry[]Base stat values (Power, Toughness, Loyalty, etc.).
AbilitiesIntrinsicAbility[]Keyword and granted abilities.

Type line helpers

You can query type membership via extension methods on CardInstance:

C# 
bool isCreature  = card.IsType(creatureType);
bool isWarrior   = card.IsSubtype(warriorSubtype);
bool isLegendary = card.IsSupertype(legendarySuper);

CardTemplate

CardTemplate is the asset you create in the Unity Editor. At minimum it holds a single CardDefinition face. Double-faced cards hold two.

C# — Creating a template at runtime (tests / procedural) 
var template = ScriptableObject.CreateInstance<CardTemplate>();
// Assign the front face via the Inspector or reflection in tests.
// In production code, assign in the Inspector and pass as a reference.
Note: In production you will always author CardTemplate assets in the Project window and reference them in Inspector fields. Creating them via ScriptableObject.CreateInstance is mainly useful for runtime tests.

CardInstance

CardInstance represents one physical copy of a card during a game. It is a plain C# object (not a ScriptableObject or MonoBehaviour) and is created via the new keyword.

C# — Constructor 
var card = new CardInstance(
    template:   cardTemplate,  // CardTemplate asset
    owner:      player1,       // Player — may be null for floating cards
    controller: player1        // Player — defaults to owner if null
);

Properties

PropertyTypeDescription
ObjectIdGuidUnique identifier assigned at construction.
TemplateCardTemplateThe source template asset.
FaceCardDefinitionCurrently active face (front by default).
OwnerPlayerPlayer who owns this card.
ControllerPlayerPlayer who currently controls this card.
CurrentZoneZoneThe zone this card currently occupies (null if unplaced).
IsTokenbooltrue if the template is a TokenDefinition.

Counters

Cards can hold any number of named counter types. Counters are plain integers stored per CounterType ScriptableObject key.

C# 
// Add two +1/+1 counters
card.AddCounters(plusOneCounterType, 2);

// Remove one counter (returns false if insufficient)
bool removed = card.RemoveCounters(plusOneCounterType, 1);

// Query current count
int total = card.GetCounters(plusOneCounterType);  // → 1
Stat counters: If a CounterType has its Has Stat Effect field enabled, every counter of that type adds the specified stat bonus. The bonus is computed via ContinuousEffectManager.ComputeState() — see Continuous Effects.

Computed State

Current stats (after all modifiers) are obtained by calling ComputeState() rather than reading raw values — this ensures layer-based effects and counters are applied correctly:

C# 
var state = context.ContinuousEffectManager.ComputeState(card);
int power     = state.GetStat(powerDef);
int toughness = state.GetStat(toughnessDef);
